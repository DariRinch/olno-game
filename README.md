# ОЛНО

ОЛНО — короткая браузерная карта одной ситуации. Игрок собирает петлю своими словами: ситуация, внутри, действие, последствие. Потом может заменить одно место и посмотреть обе петли рядом. Ничего не отправляется на сервер.

Игра Ольги Новиковой. Это веб-приложение, не лендинг. Стартовые тексты лежат в `src/game/cards.ts` и помечены как колода, которую автор заменит.

Сервера, аккаунтов и оплаты нет. Текущая партия хранится в `localStorage` браузера.

## Запуск

```bash
npm install
npm run dev
```

Сервер разработки слушает `0.0.0.0:43127`. Откройте [http://127.0.0.1:43127](http://127.0.0.1:43127).

Сборка для статической публикации:

```bash
npm run build
```

Готовые файлы появятся в `dist/`. Просмотр сборки локально:

```bash
npm run preview
```
